# Marketing Team — دليل الاستخدام

نظام لوحات داخلية لفرق التسويق والدعم في **VOID**، مبني بحيث يمكن إضافة تطبيق
جديد (بعد SETVOID) بنفس الطريقة دون تعديل أي كود برمجي — فقط ملفات JSON.

---

## 1) البنية الكاملة (أين توضع الملفات)

ضع مجلد `Marketing Team` هذا بالكامل في **جذر مستودع VOID** (نفس مستوى
`index.html`, `style.css`, `Projects/`):

```
VOID-main/
├── index.html
├── about.html
├── projects.html
├── style.css
├── main.js
├── Projects/
└── Marketing Team/                 ← هذا المجلد الجديد
    ├── index.html                  ← صفحة اختيار التطبيق (المدخل الرئيسي)
    ├── README.md                   ← هذا الملف
    └── setvoid/
        ├── index.html              ← لوحة قيادة SETVOID (التصميم الذي أرسلته)
        └── data/
            ├── project.json        ← اسم المشروع، تاريخ الإطلاق، رسالة تحفيزية
            ├── team.json           ← أعضاء الفريق (الأسماء، الأدوار، الألوان)
            ├── tasks.json          ← جدول المهام لكل يوم ولكل شخص
            ├── weekly-goals.json   ← أهداف الأسبوع (قبل/بعد الإطلاق)
            ├── updates.json        ← أهم تحديثات الأسبوع
            ├── ideas.json          ← أفكار المحتوى
            ├── achievements.json   ← إنجازات الأسبوع
            ├── team-kpis.json      ← مؤشرات الأداء لكل شخص
            ├── weekly-review.json  ← مراجعة نهاية الأسبوع
            ├── video-schedule.json ← جدول رفع الفيديوهات
            └── workflow.json       ← خطوات دورة إنتاج المحتوى
```

الرابط النهائي للوحة سيكون شيئًا مثل:
`https://<نطاقك>/Marketing%20Team/setvoid/index.html`
(المسافة في اسم المجلد تتحول تلقائيًا إلى `%20` في الروابط — لا حاجة لأي إجراء).

> **ملاحظة:** هذه اللوحة **غير مرتبطة** بأي رابط في القائمة الرئيسية للموقع
> (`index.html`, `about.html`...) عن قصد — فهي أداة داخلية للفريق فقط، تُشارك
> رابطها يدويًا مع أعضاء الفريق ولا تظهر للزوار العاديين. ملف `robots.txt`
> ووسم `noindex` داخل `Marketing Team/index.html` يمنعان ظهورها في نتائج البحث.

## 2) خطوات التنفيذ

### أ. رفع الملفات إلى المستودع (GitHub)
1. حمّل مجلد `Marketing Team` المرفق.
2. ضعه داخل مجلد مشروع VOID محليًا (بجانب `index.html`).
3. من الطرفية داخل مجلد المشروع:
   ```bash
   git add "Marketing Team"
   git commit -m "Add Marketing Team dashboard system (SETVOID)"
   git push origin main
   ```
4. بما أن `.github/workflows/main.yml` الموجود لديك يقوم بالفعل بنشر **كامل**
   المستودع (`publish_dir: ./`) عند أي push على `main`، فلن تحتاج أي إعداد
   إضافي — اللوحة ستكون منشورة تلقائيًا خلال دقيقة إلى دقيقتين.

### ب. تعديل بيانات فريق SETVOID لتصبح حقيقية
كل الأرقام والأسماء الحالية داخل `setvoid/data/*.json` هي **بيانات نموذجية**
لتوضيح الشكل فقط. عدّلها لتطابق فريقك الفعلي:

| الملف | ماذا تعدّل |
|---|---|
| `team.json` | أسماء الأعضاء الحقيقيين، الأدوار، ولون كل شخص (`violet`/`teal`/`pink`/`amber`) |
| `project.json` | `launchDate` الحقيقي (بصيغة `YYYY-MM-DDTHH:mm:ss`) والرسالة التحفيزية |
| `tasks.json` | مهام كل يوم لكل شخص (`id` يجب أن يطابق `id` في team.json) |
| `updates.json` / `ideas.json` / `achievements.json` | تحدّثها أسبوعيًا حسب سير العمل |
| `team-kpis.json` | مؤشرات الأداء الفعلية لكل عضو |
| `weekly-review.json` | تُملأ يوم مراجعة نهاية الأسبوع |
| `video-schedule.json` / `workflow.json` | جدول النشر وحالة دورة الإنتاج |

كل ملف JSON مستقل تمامًا — لا حاجة لمس كود `index.html` أبدًا، فقط الأرقام
والنصوص داخل `data/`. إذا احتوى أي ملف على خطأ في الصياغة، تعرض اللوحة تلقائيًا
تنبيهًا برتقاليًا وتستخدم بيانات افتراضية بدل أن تتعطل الصفحة بالكامل.

### ج. إضافة تطبيق جديد لاحقًا (مثل FINVOID)
النظام مبني ليتوسّع بسهولة:
1. انسخ مجلد `setvoid/` بالكامل وأعد تسميته (مثلاً `finvoid/`).
2. عدّل كل ملفات `data/*.json` داخل النسخة الجديدة لتخص فريق FINVOID.
3. افتح `Marketing Team/index.html` وفعّل بطاقة FINVOID (احذف كلاس
   `disabled` من عنصر `div.app-card` الخاص بها وحوّله إلى رابط `<a>` مثل بطاقة
   SETVOID، مع تعديل `href="./finvoid/index.html"`).
4. ادفع (`push`) التغييرات — ستظهر اللوحة الجديدة تلقائيًا.

بهذا يبقى النظام مركزيًا ومنظمًا: صفحة اختيار واحدة (`Marketing Team/index.html`)
تتفرّع منها لوحة مستقلة لكل تطبيق، وكل لوحة تُدار بالكامل عبر ملفات JSON دون
لمس أي كود.

---

## 3) ملخص سريع

- **لتعديل المحتوى الأسبوعي:** عدّل ملفات JSON فقط داخل `setvoid/data/`.
- **لإضافة تطبيق جديد:** انسخ مجلد `setvoid/`، غيّر بياناته، وأضف بطاقته في
  `Marketing Team/index.html`.
- **للنشر:** `git add` → `git commit` → `git push` — والباقي تلقائي عبر
  GitHub Actions الموجود لديك مسبقًا.
- **الخصوصية:** اللوحة غير مربوطة بالقائمة الرئيسية ومحمية من الفهرسة، لكنها
  ليست محمية بكلمة مرور — أي شخص يملك الرابط المباشر يمكنه فتحها. إذا احتجت
  حماية إضافية، أخبرني لأضيف طبقة تسجيل دخول بسيطة.
